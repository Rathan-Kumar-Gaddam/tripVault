# ✈️ TripVault — Frontend Client

This directory contains the frontend client for **TripVault**, built with React 19, Vite, and Tailwind CSS v4.

For full project documentation, architecture, features, and backend instructions, please refer to the [Root README](../README.md).

## 🚀 Quick Start (Frontend)

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Configure Environment Variables**:
   Copy `.env.example` to `.env`:
   ```bash
   cp .env.example .env
   ```
   Ensure `VITE_API_URL` points to your active backend (default: `http://localhost:5000/api`).

3. **Run development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
